# SalAveiro

📚 Sistema de Gestão de Alunos para Academia

Este projeto é um sistema completo de gestão de alunos desenvolvido com Java no backend, HTML, CSS e JavaScript no frontend e MySQL como banco de dados.

O objetivo do sistema é facilitar o controlo e organização de uma academia, centralizando todas as informações importantes num único lugar.

🚀 Funcionalidades principais
👤 Gestão de alunos
Cadastro de dados pessoais (nome, idade, contacto, etc.)
Atualização e remoção de alunos
💳 Controlo de pagamentos
Registo de mensalidades
Verificação de pagamentos em atraso
Histórico financeiro de cada aluno
🏋️ Gestão de planos
Associação de alunos a diferentes planos de treino
Atualização de planos conforme necessidade
🕒 Registo de presença
Registro da entrada de alunos através do ID
com data e hora de cada presença
Histórico de frequência
🛠️ Tecnologias utilizadas
Backend: Java
Frontend: HTML, CSS, JavaScript
Banco de dados: MySQL
🎯 Objetivo do projeto

Criar uma solução simples e eficiente para academias controlarem alunos, pagamentos, planos e presença, substituindo processos manuais por um sistema digital centralizado.
